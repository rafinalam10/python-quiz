# Python Quiz 

My first Python project!

A simple command-line quiz where you can choose a subject, answer questions and see how well you score.

### What it can do
- Choose a quiz subject.
- Get up to 5 randomly selected questions.
- Pick your answers using numbers.
- Get instant feedback on your answers.
- See your final score and percentage.

### Built with
- Python
- JSON

### How to run it

1. Clone this repository.
2. Make sure you have Python installed.
3. Open the project folder in your terminal.
4. Run:

```bash
python main.py
```

### Adding questions

You can add your own questions by editing the `questions.json` file. Just follow the same format as the existing questions.

I'm currently learning Python and wanted to build something of my own rather than just follow tutorials.
